Set up Accordion

Enter the setup code

The setup code proves you have access to the server. It's 10 letters, shown on the server's screen and in its log. You can also see it by running accordion setup-code on the server.

This server has no screen, so it doesn't need a setup code for the first 30 minutes after it starts.

Start fresh or restore

If you used Accordion before and kept backups, restore one to bring back everyone's accounts, files, and settings, including the server's name. Otherwise, set up a new server.

Go to your server

Open Accordion the way you did before.

If the page doesn't open, wait a minute while the server's name updates to point at this server, then try again.

Choose the server's name

Your devices find Accordion by this name, and it gets a certificate so browsers trust it. The name has to be under a domain whose DNS is hosted at deSEC or Cloudflare.

Certificates are listed in public logs, so choose a name that doesn't identify your household.

Accordion uses it to prove it controls the name and to point the name at the server. Limit the token to the name's A record and its _acme-challenge TXT record if your provider allows it.

Accordion gets its certificate from Let's Encrypt. Continuing means agreeing to the Let's Encrypt Subscriber Agreement.
