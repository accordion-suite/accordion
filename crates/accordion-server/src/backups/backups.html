Backups

Sign in with an admin account to manage backups.

For your security, enter your password again before you see the recovery key.

Backups keep a copy of everything on this server somewhere else, such as a USB disk, so a broken disk or a lost server doesn't lose your family's files.

Every backup is locked with a recovery key. You'll need it to get your files back if this server is ever lost, so you'll write it down first.

Your recovery key

Write it down or print it, and keep it somewhere safe away from this server. Without it, nobody can restore your backups, not even you. Spaces are optional.

Confirm that you've saved the recovery key. Backups are running, but you'll need the key to restore them.

    Where

    The full path to a folder on another disk, such as /media/usb/accordion-backups. Accordion creates the last folder if it doesn't exist.

    At your storage provider, create a private bucket for Accordion, and a key that can read and write only that bucket. Accordion keeps the key on this server, so backups run on their own.

    Some providers, such as Backblaze, keep old versions of deleted files by default. Set the bucket to keep only the last version, so the space old backups used is freed.

    Your provider shows it with the bucket. Backblaze calls it the endpoint, such as s3.us-west-004.backblazeb2.com.

    The name you gave the bucket.

    Backblaze calls it the keyID. Amazon and most other providers call it the access key ID.

    Backblaze calls it the applicationKey. Amazon and most other providers call it the secret access key.

    Accordion signs in to the other computer with its own key. On that computer, add this key as a line in ~/.ssh/authorized_keys for the user Accordion signs in as. The first time Accordion connects, it remembers how the computer identifies itself, and stops backing up if that ever changes.

    Its name or address, such as nas.local or 192.168.1.50. Add :port at the end if SSH doesn't use port 22.

    The user on that computer that Accordion signs in as.

    A full path, such as /volume1/backups/accordion, or a folder inside the user's home folder, such as backups/accordion.

    On the other computer, run rest-server, or rclone serve restic, with HTTPS and append-only mode turned on. In append-only mode, the server never lets anything delete a backup, so someone who takes over this server can't destroy them. The first time Accordion connects, it remembers the server's certificate, and stops backing up if that ever changes.

    Such as https://nas.local:8000/accordion. The last part is the folder for this server's backups.

    From the REST server's password file. Leave the username and password empty if the server doesn't ask for them.
