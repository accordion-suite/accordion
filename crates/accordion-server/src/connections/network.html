Network

Sign in with an admin account to see the server's connections.

These are all the connections Accordion makes to other computers, and why. None of them report how you use Accordion.

What this page doesn't cover

  • Connections the server's operating system makes on its own, such as system updates and setting the clock.
  • Looking up names, such as github.com. Those go through your network's DNS server, which is usually your router.
  • Backups to a USB disk or another folder on this server, which don't use the network.
