Accordion

This server is set up and running, but it doesn't have the web app, so Drive's pages don't open here.

You can still open your Drive files in File Explorer on Windows, Finder on a Mac, and many phone apps. To connect one, create an app password on your account page.

Admins can add the people in your household on the people page, check how the server is doing on the health page, set up backups on the backups page, see what's new on the updates page, and see every connection the server makes on the network page.
