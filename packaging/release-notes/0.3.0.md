The third test release adds two apps, Notes and Docs.

Notes keeps checklists, pictures, voice memos, and reminders, and you can share a note and edit it together. If an admin turns on transcripts, the server can turn a voice memo into text.

Docs writes documents with others at the same time, with fonts, tables, headers, page numbers, footnotes, and a table of contents. It prints, downloads as PDF, Word, OpenDocument, or Markdown, and opens Word, Markdown, and text files from Drive.

To bring in your notes and files from Google, upload a Google Takeout export and go to Settings, then Import from Google.

Previews and anything else that reads your files now run in a separate worker service, shut off from the network and from other files, on more systems than before, including Raspberry Pi OS. Admins can turn apps on and off on the Modules page.

Your files and settings are kept.
