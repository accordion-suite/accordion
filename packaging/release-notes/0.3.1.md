This test release fixes two problems in 0.3.0. On servers with LibreOffice, Word, Excel, and PowerPoint files now get thumbnails again. And if an update is rolled back, previews of those files keep working.

Docs adds comments. Select text to start a thread, reply, resolve it, or mention someone with @ so they hear about it. You can share a document so people can comment without editing it. Comments in Word and OpenDocument files come into Docs, and downloads keep them.

Docs also opens OpenDocument files from Drive, and older Word and Rich Text files when the server has LibreOffice.

In Notes, you can choose whether a new note starts in the title or in the note. In Drive, pointing at a file shows a card where you can star it and see where it is.

Your files and settings are kept.
